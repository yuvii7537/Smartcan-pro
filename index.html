Help Centre

Quick Start

  • Select Simulation to demo without hardware
  • Select Hardware to connect Arduino via USB
  • Click Connect → press In-Process or Final Test
  • Watch live gauges, monitor, charts in real-time
  • Generate PDF or export CSV when done

Arduino Connection

  • Close Arduino Serial Monitor before connecting
  • Baud must match sketch (default 115200)
  • Use Chrome or Edge 89+ only
  • If busy → unplug USB and replug

Arduino Output Format

ECU1 prints:

  • TX [0x100] RPM: 1500
  • TX [0x200] Speed: 85
  • TX [0x300] Temp: 92
  • TX [0x400] Fuel: 67
  • TX [0x500] Volts: 13.2

Shortcuts

  • H Help · S Settings · Space Pause · Esc Close
